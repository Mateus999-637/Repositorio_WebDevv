**Principais frameworks de JavaScript**

* **React e Angular (AngularJS)**: Atuam no desenvolvimento JavaScript no lado do cliente (*client-side*), trabalhando junto ao HTML e CSS na interface que se comunica com o servidor via HTTP. O material destaca tanto o React quanto as duas fases do Angular: o clássico *AngularJS by Google* e o ícone moderno do Angular.


* **Vue.js**: Figura entre os principais frameworks e bibliotecas de interface reunidos no panorama do ecossistema JavaScript da aula.


* **Node.js**: Ambiente sem navegador que permite executar JavaScript no lado do servidor (*server-side*), atuando na mesma camada que PHP, Java, Django e Ruby on Rails. No painel visual, também aparecem os logotipos de Deno e Bun.


* **Next.js e Gatsby**: Frameworks modernos do ecossistema web ilustrados no quadro geral de ferramentas JavaScript.


* **jQuery e Bootstrap**: O jQuery é uma biblioteca clássica identificada pelo lema *"write less, do more."* e associada ao funcionamento de componentes do Bootstrap, um framework CSS voltado para design *mobile-first* e sistemas de grid de 12 colunas.


* **Ferramentas de apoio e outras opções**: O ecossistema apresentado inclui ainda o **Babel** (conversor de sintaxe JavaScript moderna para versões mais antigas), **Mocha** e **Chai** (ferramentas de testes), além de **Ionic**, **Ember**, **Meteor**, **Mithril**, **Aurelia** e **D3**.
